# mod_fraction - Frações

Atividade-ferramenta para Moodle que permite simplificar e comparar frações, somar, subtrair, multiplicar, dividir e converter fração ↔ decimal.

Cada resultado mostra as contas utilizadas, incluindo MDC pelo algoritmo de Euclides, MMC, equivalência de denominadores, multiplicação cruzada, simplificação e divisão decimal.

## Requisitos

- Moodle 4.5 ou superior.
- Os cálculos são executados no navegador e não são armazenados.

## Instalação

Copie a pasta `fraction` para `mod/fraction` e conclua a atualização pelo Moodle.
